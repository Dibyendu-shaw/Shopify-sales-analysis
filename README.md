# Shopify-sales-analysis
# 🛒 Shopify E-Commerce Sales & Customer RFM Intelligence Suite

An end-to-end Power BI business intelligence and analytics solution analyzing transaction velocity, category contribution, and customer lifetime value (RFM Segmentation) for a multi-million-dollar Shopify storefront.

---

## 📌 Project Overview
* **Domain:** E-Commerce / Retail Analytics
* **Tools Used:** Microsoft Power BI, Power Query, DAX, Star Schema Data Modeling
* **Dataset Scope:** 7,431 Transactions | $4.60M Gross Revenue | 4,431 Unique Customers

---

## 📊 Key Business Performance Indicators (KPIs)
* **Total Gross Revenue:** $4.60M ($4,598,960.87)[cite: 1, 2]
* **Total Orders Fulfilled:** 7,431[cite: 1, 2]
* **Average Order Value (AOV):** $618.89[cite: 1, 2]
* **Total Unique Customers:** 4,431[cite: 1, 2]
* **Repeat Customer Rate:** 46.02% (~$1.85M generated by repeat purchasers)[cite: 1, 2]

---

## 🏗️ Data Architecture & Star Schema Model

The raw flat sales data was transformed into an optimized Star Schema with explicit fact, dimension, and measure storage tables[cite: 1, 2]:

| Table Name | Type | Key Column | Cardinality & Filter Direction | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **`shopify_sales`** | Fact Table | `Invoice Date`, `Customer Id` | Central Fact | Core transaction logs, line-item pricing, quantities, state locations[cite: 1, 2] |
| **`Dim_Date`** | DAX Dimension | `Date` | `1 : *` (Single) | Calendar intelligence, Day of Week sort index (`Day No`), Year/Month hierarchies[cite: 1, 2] |
| **`Dim_Customers_RFM`** | DAX Dimension | `Customer Id` | `1 : *` (Bidirectional) | Customer summary metrics (Recency, Frequency, Monetary) & RFM segment labels[cite: 1, 2] |
| **`Measures (2)`** | Measure Group | — | — | Centralized repository for all DAX KPI calculations[cite: 1, 2] |
